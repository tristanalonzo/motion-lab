# 000 — tristan’s motion lab

The front page: two lines on what this lab is and who's making it, then how to get into the list. It's the first thing in the list and where the site opens.

## States

None. It's text.

## Decisions

- **It's an experiment folder like any other.** The site has no special code for it; it follows the same contract as 001.
- **The words.** "buttons that do a little too much." says what's on the shelf with a wink, instead of a description like "a library of interactive experiments" that fits any portfolio. The second line says who's making it and that it's a learning log, so rough edges read as honest, not unfinished.
- **All lowercase, on purpose.** Matches "tristan's motion lab" and the list.
- **The ↓ is drawn as a key, not just an arrow.** A little keycap tells you it's something to press, not decoration. Rounded square with a slightly heavier bottom edge, like a Mac key. It's a picture of a key, not a button, so the pill-or-circle rule doesn't apply.
