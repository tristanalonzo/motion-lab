# 000 — tristan’s motion lab

The front page: a few lines on what this lab is. It's the first thing in the list and where the site opens.

## States

None. It's text.

## Decisions

- **It's an experiment folder like any other.** The site has no special code for it; it follows the same contract as 001.
- **All lowercase, on purpose.** Matches "tristan's motion lab" and the list.
- **The ↓ is drawn as a key, not just an arrow.** A little keycap tells you it's something to press, not decoration. Rounded square with a slightly heavier bottom edge, like a Mac key. It's a picture of a key, not a button, so the pill-or-circle rule doesn't apply.
